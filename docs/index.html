轻装上桌

主程序负责界面和窗口。新闻、短剧和播放组件分别安装，不用就卸载。

各忙各的

切到一个功能，其他功能静默。收起窗口时暂停内容任务，回来看时保留位置。

自由接入

新闻与短剧服务通过独立 API 提供数据。你可以使用自己的前端接入服务。

BriefDock 1.0.0 将新闻浮窗扩展为新闻与短剧双页面应用。

- 红果短剧：扫码登录、安全保存身份、账号收藏同步、封面搜索与收藏页、跨端观看进度同步。
- Windows 原生播放器：按需 Range 取流，360p/480p/720p，播放/暂停、选集、上一集/下一集、进度跳转与音量；倍速保持音高，播完自动下一集。
- 紧凑悬停控制栏、统一 Fluent 图标，收藏星标即时反馈，后台同步失败回滚。
- 保留透明度、置顶、贴边与页面静默；隐藏时只暂停，静音仅由用户选择。
- 完整 CLI 控制与后台截图，真实系统输入通过隔离 runner 验收。
- 安装包自带 Windows 播放及账号辅助依赖，无需预装 Python、Go 或 GStreamer。

Windows x64 支持应用内更新。macOS 13+ 继续提供 Apple 芯片与 Intel 预览包；本次红果原生播放及账号辅助链路为 Windows 功能，未宣称 macOS 功能对等。macOS 应用仍为临时签名，尚未公证。

可观看内容与清晰度取决于上游服务及账号权限，不承诺全部剧集或 1080p。首次扫码新会话完整人工验收、手机 App 刷新表现及长期音画同步仍不在本轮自动验证范围。

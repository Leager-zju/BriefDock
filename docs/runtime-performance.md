# 运行时性能测试与优化复盘（2026-11-13）

## 结论

确认并修复了视频 EOS 后解码线程空转：同一合成短片单独测试，修复前约 98.7% 单逻辑核，修复后 0.00%；实际片尾及 seek 后恢复播放也通过。封面缓存改为仅保留当前搜索与收藏仍引用的图片，防止随历史关键词无限累积。CLI 单请求执行器改用当前线程，避免每次查询创建整组工作线程。

没有证据支持此时更换播放器。真实 720p 解码 CPU 约占整机 1.37%，但进程树私有内存约 457 MiB，关闭播放器后的保留内存仍明显高于初始新闻页；本轮没有完成堆/显存归因，不把它宣称为已解决或已确定的泄漏。

## 方法与覆盖

- Windows x64 / Release / 24 逻辑 CPU；屏幕外窗口且禁用自身物理输入，不能外推前台显示器合成与真实交互负载；新闻为 53 个来源、每源 30 条长标题，共 1590 条新鲜样例，确认没有启动新闻网络刷新。红果使用保存身份、58 项实际收藏及此前授权的固定剧集，收藏写入和云端进度上传始终关闭，零音量。
- 测量首次/后续启动、新闻/收藏/搜索、筛选、窗口缩放、renderer 捕获、设置开关、720p 播放/暂停、3 次切集/跳转、360p/480p/720p 切换、末集 EOS/恢复、隐藏、释放与切页循环。最终完整轮通过且 foreground_unchanged=true。
- 稳态采样以 0.25 秒为等待间隔（实际包含保护与统计开销），单阶段约 5–12 秒；CPU 为测试进程树累计 CPU 时间增量，保留已退出子进程的已采样时间，以 PID+创建时间防复用。短于采样间隔的子进程可能遗漏部分峰值和 CPU，峰值为采样峰值，不是系统全时峰值。
- 内存为进程树私有提交与工作集，工作集含共享页；未量化 GPU 显存。响应数据是 CLI 发起到业务回复/状态确认，含 CLI 启动和前台观察器开销，不等同点击到显示器呈现。accepted 类操作仅表示接收；切集和跳转另等实际视频/音频状态。
- OS 缓存未清空，不能称真正冷启动。前后网络、媒体片段和图形缓存存在波动，P95 在 n=3/5 时仅是该小样本高分位，不作长期 SLA。

## 仍存在的瓶颈和取舍

1. 首次窗口/渲染初始化是明确的主要启动区间。进一步优化需对 compositor、适配器选择、shader/字体初始化继续分段，不能以更换 CPU 渲染或缩放位图牺牲视频集成和清晰度。
2. 首播仍约 6–7 秒，切集约 1.8 秒；账号核对、网络与解码准备均占时间。保留权限核对，不用缓存过期凭据、跳过身份校验、预加载下一集或放宽 CDN 边界换取速度。
3. 收藏加载期仍有解码/私有 Python 启动开销，完成后 CPU 接近零。未为短暂加载期引入常驻更多进程或大幅提高并发，以免增加峰值内存及取消复杂度。
4. 视频及多种清晰度使用后，进程保留内存高于初始新闻页，短轮切页未继续上升。本轮没有堆分配/模块/显存完整归因；运行库、图形缓存和分配器保留容量只是候选解释，不能当成已证实根因，也不能据短轮认定无长期泄漏。不使用 EmptyWorkingSet 等方式制造工作集下降。

## 验证、失败与证据

- 新增单独运行的 EOS CPU 用例：修复前失败（约 98.7% 单核），修复后通过（0.00%）；该性能用例默认忽略，避免与并行测试争抢进程 CPU。另 14 项 Release 相关测试全通过；fmt/diff 检查通过。真实 Range MP4 片尾 seek/播放恢复通过。
- 最初样例解析遗漏常量，启动前断言失败，未启动实例；第一实测轮误选收藏首项而媒体不可用，随后固定到此前授权的剧集。两轮因前台保护停止，其中后一轮确认拥有前台的是测试 App 自身，未确定触发原因；最终仅对 QA 窗口禁用物理输入并保留 NOACTIVATE/TOOLWINDOW，完整复测通过。未把这个设置施加到用户实例，也不作为普通窗口焦点行为验收。
- 限帧合成源的额外复播断言未通过，不计为产品恢复成功；实际可寻址输入的片尾跳转/恢复另行通过。没有为让基准通过放宽权限或控件安全校验。
- 精简 JSON 证据收尾归并至 `target/verification-history/`，目录名保持各轮名称：`qa-perf-baseline-20261113-run2`、`qa-perf-baseline-20261113-complete`、`qa-perf-media-diagnostic-20261113`、`qa-perf-optimized-20261113-final`、`qa-perf-startup-breakdown-20261113`、`qa-perf-startup-trace-20261113`。源码基线为 d1fc398，测得 Release 版本为 1.0.1，优化代码尚未提交。
- 未进行 GPU 显存/堆采样、长时压力/泄漏、音频主观听感、macOS 性能或真实桌面输入测试；未改用户账号收藏/云端进度、未重启现用实例、未发布新版本。

## 复现

在准备好的 Windows 私有 SDK 环境中，通过 `scripts/benchmark-runtime.py --real --app-exe <独立 Release EXE> --output target/qa-perf-唯一名称` 运行。`--seconds` 控制稳态阶段时长（5–60 秒），`--repeats` 控制 CLI 样本数（5–100）；`--startup-only` 只测隐藏启动，`--media-only --real` 只测已授权固定媒体。脚本关闭收藏/进度写入与声音，不应对用户 default 实例执行。

EOS 性能定向：`cargo test --release --target x86_64-pc-windows-msvc --bin news-float ended_video_worker_does_not_busy_spin -- --ignored --nocapture`，需先加载 `scripts/native-player-env.ps1`。
